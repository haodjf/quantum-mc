# 量子蒙特卡罗（MCWF）Julia 代码结构与工作原理说明

本文档面向后续维护者，系统解释本仓库中 Julia 版本 MCWF 代码的结构、核心算法、性能设计点，以及与 MATLAB 版本的逻辑对应关系。

---

## 1. 代码总览

当前实现的核心文件如下：

- `src/QuantumMC.jl`：包入口（module wrapper），负责导出子模块。
- `src/MCWFOptimized.jl`：MCWF 主实现（参数、单轨迹、并行、多通道跳转逻辑）。
- `scripts/verify_against_matlab.jl`：与 MATLAB 参考结果进行分布一致性检验。
- `scripts/benchmark.jl`：性能测试脚本，支持与 MATLAB `parfor` 耗时对比。
- `Project.toml`：依赖声明。

从分层角度看，可分为三层：

1. **物理模型层**：参数、哈密顿量近似更新、跳跃规则。
2. **数值执行层**：单轨迹循环、状态更新、归一化、末态统计。
3. **工程性能层**：缓存复用、线程并行、线程本地 RNG、脚本化验证/基准。

---

## 2. 模块入口：`src/QuantumMC.jl`

该文件只做一件事：把 `MCWFOptimized` 子模块包含并导出。

- 优点：后续可在包层新增更多模块（如 IO、可视化、数据分析），保持主逻辑模块独立。
- 典型调用方式：

```julia
using QuantumMC
using QuantumMC.MCWFOptimized
```

## 3. 主实现文件：`src/MCWFOptimized.jl`

这是最关键的文件，包含几乎全部数值算法。

### 3.1 参数结构体

#### `MCWFParams`
用于存放物理常量与实验几何参数，例如：

- 原子相关：`m`, `tau`, `nu_0`
- 激光/波包相关：`w0`, `cg`
- 时间与几何：`dt_scale`, `t2`, `t3`, `d3`
- 动量离散窗口：`p`（决定 `num1 = 2p + 1`）

**作用**：把“物理配置”从算法实现中解耦，方便参数扫描与可重复实验。

#### `RunConfig`
用于存放一次仿真的运行参数：

- `i_sat`：饱和参数（影响 Rabi 频率）
- `detuning`：失谐
- `trajectories`：轨迹数
- `no_jump_step`：No-jump 矩阵重建步长
- `seed`：随机种子

**作用**：把“运行配置”从模型常量中解耦，利于 benchmark/复现实验。

---

### 3.2 缓存结构体：`TrajCache`

`TrajCache` 是性能关键，用于承载每条线程可复用的内存：

- `ψ`：当前 2N 复振幅状态向量
- `ψtmp`：矩阵乘法临时向量
- `ψg`：跃迁后基态分量（用于最终概率统计）
- `nojump`：No-jump 演化矩阵
- `kinetic`：预计算动能项
- `ybuf`：预留坐标缓冲（便于未来扩展轨迹记录）

**为什么重要**：避免在热循环内反复分配数组，降低 GC 压力。

---

### 3.3 物理辅助函数

#### `_γ`, `_k`, `_vrec`, `_num1`
- 分别计算自然线宽、波矢、反冲速度、动量基维度。
- 都是内联小函数，便于编译器优化。

#### `build_quantumoptics_system`
- 使用 QuantumOptics.jl 构建 `MomentumBasis` 与 `NLevelBasis(2)` 的张量基。
- 当前主热循环并未直接调用 QuantumOptics 的通用求解器，而是手写了更轻量更新以追求极致性能。

这是一种典型策略：
- **框架层**用于表达模型与后续可扩展性；
- **热路径层**用手写内核获取速度。

---

### 3.4 No-jump 演化矩阵更新：`_build_nojump!`

该函数实现“无跳跃条件下”的离散一步更新矩阵构造：

1. 清零已有矩阵（复用内存）。
2. 计算当前时刻高斯包络 `off`（对应时变耦合）。
3. 填充对角块：激发态与基态能量项（含衰减项）。
4. 填充上下耦合带（相邻动量通道耦合）。

与 MATLAB 版本相比，关键优化是：

- 不再在循环中不断新建稀疏矩阵；
- 改为固定大小 dense 矩阵原地改写；
- 配合 `mul!` 实现无额外分配的矩阵-向量乘。

> 注意：当前实现追求速度，采用了一阶离散传播近似（与 MATLAB 中 `matrix_tot_1` 对齐思路）。

---

### 3.5 跳跃通道数学与状态操作

#### `_normalize!`
原地归一化，确保波函数范数为 1。

#### `_jump_to_ground!`
将激发块映射到基态块（对应 MATLAB 中 `matrix_jump_0*vec` 的等价动作），并归一化。

#### `_ep31` / `_ep32`
实现原 MATLAB 代码里用于角度采样的特殊公式（含 `acos`、立方根及复数分支），用于反冲角计算。

---

### 3.6 单轨迹主循环：`run_trajectory!`

该函数对应 MATLAB 的 `for j02=1:j02_stop` 主演化循环。

每步逻辑如下：

1. **必要时重建 no-jump 矩阵**（每 `no_jump_step` 步，或发生跳跃后）。
2. 计算跳跃概率 `dp = γ * dt * ||ψ_e||^2`。
3. 抽样随机数判断：
   - `ep1 > dp`：No-jump 演化（矩阵乘 + 归一化）。
   - 否则进入跳跃分支。
4. **三通道跳跃分支**（概率各 1/3）：
   - `ep2 > 2/3`：**Quench**，直接终止轨迹。
   - `ep2 < 1/3`：**Recoil**，更新速度 `v1 += vrec*cos(ep4)*sin(θ)`，继续循环。
   - 其他：**Reset**，投影并更新一次反冲后终止（对齐原脚本 `break` 分支）。
5. 轨迹结束后，把各动量通道映射到 slit3 空间位置，累加被探测概率。

返回值：

- `detected`：该轨迹贡献的探测计数
- `ψg` 拷贝：该轨迹末态分布（供统计平均）

---

### 3.7 多轨迹并行：`run_ensemble`

`run_ensemble` 使用 `Threads.@threads` 并行遍历轨迹。

关键并行设计：

1. **线程本地 RNG**：`rngs[tid]`，避免锁竞争。
2. **线程本地缓存**：`caches[tid]`，避免跨线程写冲突。
3. **线程本地累加器**：`counts[tid]`, `probs[tid]`，最后再规约。

这样做的结果：

- 无需原子操作；
- 降低 false sharing 风险；
- 具有较好可扩展性（取决于 CPU 与内存带宽）。

## 4. MATLAB 对标验证脚本

文件：`scripts/verify_against_matlab.jl`

### 目的
在固定随机种子和同参数下，对比 Julia 与 MATLAB 的末态分布偏差。

### 输入
- `.mat` 文件（需含 `probability_ref` 向量）

### 输出
- `max |p_julia - p_matlab|`
- 并打印是否满足 `<= 1e-10`

### 说明
要真正达到机器级一致性，必须确保：

1. 两边使用严格一致的随机数序列策略；
2. 公式分支与浮点顺序完全对齐；
3. 迭代停止条件和初值采样一致。

如果未来发现误差 > `1e-10`，通常需要做“随机数流逐步对齐”的精细化改造。

## 5. Benchmark 脚本

文件：`scripts/benchmark.jl`

功能：

- 用 `BenchmarkTools` 测 Julia 版本最短运行时间；
- 打印吞吐量（traj/s）；
- 若提供 MATLAB `parfor` 耗时（秒），则输出 speedup 倍数。

建议测试流程：

1. `-t 1` 跑单线程基线。
2. `-t auto` 跑多线程。
3. 保持轨迹数一致（如 2e5, 1e6）对比 MATLAB。

---

## 6. 与原 MATLAB 逻辑的映射关系（重点）

- MATLAB `vec0/vec1/vec2`：对应 Julia 中 `ψ/ψtmp/ψg`。
- MATLAB `nojump=sparse(matrix_tot_1)`：对应 Julia `_build_nojump!` + `mul!`。
- MATLAB `if ep2>2/3 ... elseif ep2<1/3 ... else ...`：对应 Julia 三通道分支。
- MATLAB 速度更新公式：在 Julia 中保留 `v1 += vrec*cos(ep4)*sin(θ)` 结构。
- MATLAB 最后 slit3 计数：Julia 中同样按每个动量通道映射坐标并累加。

## 7. 后续扩展建议

1. **轨迹记录功能**
   - 可在 `TrajCache` 增加时间序列缓冲区；
   - 在 `run_trajectory!` 中按需采样存储（建议稀疏采样，避免 I/O 成瓶颈）。

2. **更严格的 MATLAB bitwise 对齐**
   - 预生成随机数组并按完全一致顺序消费；
   - 用同构公式和同顺序运算控制浮点误差路径。

3. **进一步性能优化方向**
   - 用 `LoopVectorization.jl`/`@turbo` 优化热点循环（先做正确性回归）；
   - 评估 `StaticArrays`（维度较小时可能收益明显）；
   - 增加 NUMA/线程绑定测试以稳定大规模并行吞吐。

## 8. 结语

本实现核心目标是：

- 保留原 MATLAB 三通道 MCWF 的关键物理流程；
- 在 Julia 中通过“缓存复用 + 原地计算 + 线程并行”达到高性能执行；
- 提供可落地的验证与 benchmark 工具链，方便持续对标 MATLAB 并迭代优化。
